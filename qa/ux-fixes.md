# 体验问题检查与修复记录

核查日期：2026-10-24。本清单记录开发版本中通过代码检查、真实 SQL 运行或浏览器操作发现的问题，以及已实现的修复；不是把尚未实现的功能算成已修复缺陷。考试知识为主，运行器帮助学生理解纸面题目。

## SQL 与判题：18 项

| # | 发现的问题及学生受到的影响 | 修复与验证 |
|---|---|---|
| 1 | 空表建表任务漏写必要 NOT NULL 也能通过 | 比较非空约束，主键非空语义保持一致；真实建表错答回归。 |
| 2 | INT / INTEGER 等考试接受的类型别名按字面比较，被误判 | 规范化有来源的类型等价写法，长度仍参与比较；别名/错误长度回归。 |
| 3 | 外键声明顺序改变 SQLite 内部编号，正确结构被误判 | 比较实际引用关系，忽略内部编号和独立约束声明顺序；换序/错误引用回归。 |
| 4 | 建表列顺序与参考不同即判错，虽然题目未限制顺序 | 按字段映射比较结构和数据；SELECT 输出顺序仍按题意检查。 |
| 5 | 题目要求聚合标题，但漏写别名仍获得正确反馈 | 指定需命名的列，允许合理的不同标题；有/无别名实际查询测试。 |
| 6 | 所有数值四舍五入到八位，小数差异被吞掉 | 仅容忍浮点计算量级的误差；小数与零、不同行排序测试。 |
| 7 | CREATE DATABASE 名称不对时提示笼统，学生看不出原因 | 保留名称比较，反馈明确指向目标名称；建库错名测试。 |
| 8 | 第二个判题数据库初始化失败时，第一个未关闭 | 统一 finally 关闭已创建实例，避免失败重试积累资源。 |
| 9 | UPDATE 题目标当前为空时，仅 SELECT 也可能得到相同状态 | 同时检查任务操作类别；空目标记录回归。 |
| 10 | 查询题允许先改变源数据，再返回参考结果 | 查询答案必须保留源数据；批量修改后查询回归。 |
| 11 | sql.js 导出快照后连接重开，外键检查失效 | 每次导出后恢复 foreign_keys，验证导出后的非法引用被拦截。 |
| 12 | 空数据库批量操作失败，无法正确回到操作前状态 | 包含数据库名称的完整快照回滚；建库后错误语句回归。 |
| 13 | SQLite 将 INTEGER 主键 NULL 自动编号，掩盖必填键错误 | 明确验证主键非空；插入空键回归。 |
| 14 | 真题里名为 ORDER 的表被错认成排序子句 | 仅将 ORDER BY 组合识别为子句，保留原表名；ORDER 表/多字段排序回归。 |
| 15 | 零行 SELECT 丢失字段表头，错误投影也可能被判对 | 通过 prepared statement 读取列信息；空结果列宽回归与表格检查。 |
| 16 | SELECT Name, SUM(Score) 返回任意姓名，误导聚合概念 | 检查普通字段是否分组或由分组主键确定；错误混合/正确主键依赖/别名回归。 |
| 17 | IG 只检查第一个 LIKE，后续通配条件绕过范围 | 逐一验证全部 LIKE 条件；双条件范围回归。 |
| 18 | 按客户姓名排序时存在同名记录，未规定次序却严格判分 | 相关原创题明确同名时按 CustomerID 次排序，题干/答案/提示同步。 |

上述判题细节及案例见 [判题审计](grading-audit.md)、[engine tests](../tests/engine.test.mjs)、[grader tests](../tests/grader.test.mjs)。历史写法的接受条件仍受各题证据和本练习范围约束。

## 验收方式与范围

- 单元/集成：全部题库参考解、补充数据、16 课示例、真实错答、状态恢复。
- 浏览器流程：真实 SQL 运行、错误提示、草稿刷新、收藏、提示、搜索空状态、维护任务更新显示、实验室恢复、范围切换、键盘、41 条来源、导出/导入、限时挑战、主题、离线和 Worker。
- 布局：390×844、360×740、768×1024、1024×768、1440×1050；检查八个主要页面的横向溢出并查看截图。
- 引擎：Microsoft Edge（Chromium）与 Windows 上的 Playwright WebKit 27.2。WebKit 检查不是实际 iPad 硬件验收；iOS 安装入口及系统权限受设备浏览器控制。
- 仅在 HTTPS/localhost 启用离线 PWA，局域网 HTTP 保留在线使用能力。外部试卷链接不承诺离线可用。

这里没有声称有限测试能证明所有未来输入和设备永远不存在问题；交付标准是上述需求闭环、已发现缺陷修复和可重现验收均通过。
