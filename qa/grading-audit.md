# 自动判题审计

日期：2026-10-24。证据依据：[20 份 9618 试卷与评分标准](../docs/research/as-paper-audit.md)。本记录只描述实际发现的判分问题和对应修复；测试执行结果在集成验证后记录。

## 已发现并修复的问题

| 问题 | 对学习者的影响 | 修复及回归场景 |
| --- | --- | --- |
| 表结构比较忽略非空限制 | 空表建表题漏写必要的 NOT NULL 仍能得分 | 比较非键字段的非空约束；主键的非空含义视为隐含。测试缺失必填 Label。 |
| 数据类型按原始拼写比较 | 评分标准允许的 INT/INTEGER、CHAR/CHARACTER 等等价形式会被判错 | 按已支持类型别名规范化；保留长度，防止过短字段获得相同评价。 |
| 外键元数据的声明顺序被当成语义 | 两个外键顺序调换，SQLite 分配的内部编号改变，正确答案会被判错 | 忽略内部编号、规范化约束组顺序，保留实际引用表和字段；测试换序与错误目标。 |
| 建表列声明顺序被当成答案顺序 | 字段和约束完全相同的合法建表答案可能被判错 | 按字段名比较结构，同时把已有行映射到对应字段后比对。查询输出仍严格检查列顺序。 |
| 不检查题目明确要求的聚合标题 | 数字正确但漏掉命名要求的答案获得满分 | 使用题目 `aliasColumns` 元数据检查相关输出列；允许不同于示例的合理标题。 |
| 所有数值统一保留 8 位小数 | 很小但不同的实数被错误合并，甚至与零相等 | 只容忍浮点运算量级内的误差；测试零与非零小数，以及相近实数的行序。 |
| 建库名称错误只收到泛化提示 | 学生难以看出内容状态相同但名称不符 | 保留名称比较，并给出具体数据库名称反馈。 |
| 第二个隔离数据库初始化失败时，第一个实例可能未关闭 | 初始化失败后资源不能及时释放 | 在同一个 try/finally 中初始化并分别关闭已经成功创建的实例。 |
| 写操作未命中记录时，普通 SELECT 也可能通过 | 只因最终表状态没变，就把未完成写操作的答案判为正确 | 写操作题同时要求对应操作类型，不能由无修改查询冒充。 |
| 查询前修改原始数据，再返回匹配行 | 只比结果，无法识别学习者改变题目数据后作答 | 查询题还比较原始表状态与数据库名称；含写操作的查询答案给出专门反馈。 |

## 防止“碰巧做对”的验证

测试使用真实 SQL 引擎，而非伪造返回值来证明被测代码与自己一致：

- 示例里没有边界分数时，错误的严格比较会与正确的包含边界比较返回一样结果；补充恰好处于边界的记录后必须判错。
- 按可见正确答案中的姓名硬编码条件，加入另一个符合条件的姓名后必须判错。
- UPDATE 漏写 WHERE、更新边界错误、INSERT 数值错误，即使语句执行成功也必须判错。
- 新建表还没有任何记录时，遗漏外键、错误主键、错误类型和遗漏非空条件仍必须判错。
- 对无排序要求的 SELECT，允许行顺序变化，但保留重复行次数、NULL 与文本差异、投影列数和列顺序。
- 对要求排序的题，反向排序必须判错。
- 无匹配记录时仍检查实际输出字段数量，避免空结果掩盖错误的字段列表；执行器保留空查询表头。
- CREATE DATABASE 的目标名称必须与题设一致；标识符大小写差异不影响判分。

测试文件为 [tests/grader.test.mjs](../tests/grader.test.mjs)。其中完整课程检查会遍历课程导出的所有练习：SQL 题使用参考解运行示例与补充数据，预测题用实际查询结果核对 CSV 答案，概念题检查答案索引有效性。另逐课从该课公开数据集的初始状态运行示例，不额外补入用户在实验室不会得到的 setup。测试要求至少 49 题与 16 课，防止通过删减内容使检查表面通过。

## 判分边界

- 自动判题验证本练习的要求和数据库结果，不宣称模拟 Cambridge 的全部人工评分判断或分步给分。
- 类型别名兼容不能覆盖课程范围检查；不在目标考试范围的语法仍由执行器拦截。
- 列标题检查能识别遗漏标题，但不会声称能自动判断所有自然语言标题是否足够贴切。
- 补充数据检查能有效抓住已覆盖的常见错法，不能数学上证明任意 SQL 与参考解在所有可能数据库上等价。

## 执行结果

最终命令：`node --test tests/grader.test.mjs`。

结果：**89 项通过，0 项失败，0 项跳过**；运行约 1.1 秒。

- 22 组判题回归：真实 SQL 执行与结果语义比较，包括正确写法和典型错答。
- 49 个课程任务：40 个 SQL 任务的参考解及全部配置的补充数据、3 个预测任务的实际输出、6 个概念题的答案索引。
- 16 个教学示例：各自仅使用公开数据集初始数据即可直接执行，涵盖查询、维护和 DDL。
- 另外 2 项为上述课程任务组和教学示例组的汇总测试，Node 的 89 总数包含这两项。

没有发现需要绕过的课程/执行器不兼容，也没有通过跳过题目来获得通过结果。`src/grader.js` 与测试文件已通过 JavaScript 语法检查。此次仅修改判题器、该测试文件及本审计文档，未构建发布产物。
